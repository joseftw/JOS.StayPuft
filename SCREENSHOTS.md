## Technical Details

- **Generated by**: `generate.js` static site generator
- **Content source**: Markdown files in `posts/` directory
- **CSS/JS**: Built from `assets/` directory using existing build system
- **Output**: Pure HTML/CSS/JS in `dist/` directory
- **No runtime dependencies**: Can be deployed anywhere
