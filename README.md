# JOS.StayPuft

**Now available as a Static Site Generator!** 🎉

This theme has been converted from a Ghost theme to a static site generator that reads markdown files and generates HTML pages. See [STATIC-SITE.md](STATIC-SITE.md) for complete documentation.

## Quick Start (Static Site)

```bash
npm install
npm run build
npm run fetch-posts  # Optional: fetch existing posts from RSS
npm run generate     # Generate static site in dist/
```

---

Fork of [dlecina/StayPuft](https://github.com/dlecina/StayPuft).
I've removed the Search and all other stuff that used jQuery.

Works with ghost 3.0+

## Features

* Giscus comments
* Custom Fontawesome font (only contains icons that are being used by the theme).
